# Tableau Analysis![Tableau](https://www.talkwalker.com/hubfs/Website/Logos/marketplace/Tableau.png)


## Overview

This repository hosts the Tableau workbook and supporting documentation for an in-depth data analysis project focusing on **Sales Performance Across Regions**. This dashboard aims to provide interactive insights into **key performance indicators, underlying patterns, and regional performance drivers**.



## 📈 Key Visualizations & Concepts

This dashboard leverages various Tableau chart types and analytical concepts to present data effectively. Below, we explain the purpose and insights derived from each type of visualization used.

### 1. Bar Charts

**Purpose**: Bar charts are excellent for comparing categorical data.

**In this Dashboard**:
- Sales by Product Category to identify top-performing categories.
- Customer Count by Region to analyze geographic distribution.

![Screenshot of a Bar Chart](replace-with-bar-chart-screenshot.png)

### 2. Line Charts

**Purpose**: Display trends over time.

**In this Dashboard**:
- Monthly Revenue Trend to observe seasonal patterns.
- Daily Website Visitors to identify peak traffic periods.

![Screenshot of a Line Chart](replace-with-line-chart-screenshot.png)

### 3. Area Charts

**Purpose**: Show cumulative values over time.

**In this Dashboard**:
- Cumulative Sales by Quarter.
- Stacked Area Chart for Product Sub-Category contributions.

![Screenshot of an Area Chart](replace-with-area-chart-screenshot.png)

### 4. Histograms

**Purpose**: Display distribution of numeric data.

**In this Dashboard**:
- Customer Age Distribution.
- Order Value Distribution.

![Screenshot of a Histogram](replace-with-histogram-screenshot.png)

### 5. Group By Concept

**Explanation**: Combine multiple dimension members into higher categories.

**Examples**:
- Grouping States into Regions (North, South, East, West).
- Grouping Product Sub-Types into Product Families.

### 6. Set Concept

**Explanation**: Define custom subsets for comparative analysis.

**Examples**:
- Top N Customers by Sales.
- High-Profit Products Set based on profit margin.

### 7. Hierarchy Concept

**Explanation**: Structured arrangement for drill down/up analysis.

**Examples**:
- Date Hierarchy: Year > Quarter > Month > Day
- Geographic Hierarchy: Country > State > City
- Product Hierarchy: Category > Sub-Category > Product Name

## 📊 Statistical Insights & Visualizations

- **Mean/Average**: Shown via reference lines in bar charts.
- **Median**: Used in box plots as a central value.
- **Standard Deviation**: Visualized using distribution bands.
- **Count/Frequency**: Displayed in histograms.
- **Percent of Total**: Highlighted in stacked charts.
- **Trend Lines**: Applied in line charts to project trends.

## 💡 How to Use This Dashboard

- **Interact with Filters**: Select Region, Category, Date, etc.
- **Drill Down/Up**: Use + / - icons in hierarchies.
- **Hover for Tooltips**: See detailed insights.
- **Explore Sets/Groups**: Click to highlight Top N customers or High-Profit products.
